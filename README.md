# 🎮 ServerOS — 성인 종합 게임 커뮤니티 올인원 디스코드 봇 & 대시보드

명령어 입력의 번거로움 없이 **디스코드 2.0 원터치 상호작용 패널(Button, Modal, Select Menu)**과 **Next.js 실시간 웹 대시보드**로 서버 전체를 스마트하게 운영하는 올인원 시스템입니다.

---

## 🌟 주요 기능

1. **🔞 성인 인증 & 온보딩 패널**
   - 만 19세 미만 미성년자 차단 및 매너 서약 모달
   - 클릭 즉시 성인 인증 역할 부여
   - 인기 게임(롤, 발로란트, 배그, 헬다이버즈 등) 다중 선택 역할 배정
2. **🎮 원터치 파티 구인 (LFG) 시스템**
   - `[파티 구인 생성]` 버튼 ➡️ 게임명, 제목, 정원 모달 입력
   - 실시간 인원 반영형 카드 (`[파티 참가]`, `[참가 취소]`, `[조기 마감]`)
   - 인원이 다 차면 자동으로 파티원 전원 멘션 및 음성방 소집
3. **🎙️ 스마트 음성방 자동 생성 (Voice Master)**
   - `➕ 방 만들기` 음성 채널 입장 시 개인 전용 임시 음성방 자동 생성
   - 음성 채널 리모컨 제공: `[🔒 방 잠금/해제]`, `[👥 인원 제한]`, `[✏️ 이름 변경]`
   - 모든 유저 퇴장 시 채널 자동 삭제 (서버 채널 목록 깔끔 유지)
4. **🛡️ 클린 매너 케어 & 1:1 비밀 신고 티켓**
   - 음주 비매너, 성희롱, 트롤링 발생 시 관리자 1:1 비밀 채널 즉시 생성
5. **📊 Next.js 웹 대시보드**
   - Discord Rich Presence 기반 **지금 가장 많이 하는 게임 Top 5** 실시간 집계
   - 24시간 게이머 피크타임(21:00 ~ 02:00) 분석 차트
   - 디스코드 실시간 렌더링 미리보기 지원 **원터치 공지 빌더**
   - 연령대별 분포도 및 신고 로그 관제

## 📁 프로젝트 구조

```
discordhelper/
├── backend/                  # Python 백엔드 및 디스코드 봇
│   ├── api/
│   │   └── main.py           # FastAPI 대시보드 API (실시간 통계 및 공지 연동)
│   ├── bot/
│   │   ├── core/bot.py       # discord.py 2.0 봇 코어 및 Persistent Views
│   │   └── cogs/
│   │       ├── onboarding.py   # 성인 인증 & 게임 역할 선택
│   │       ├── party_lfg.py    # 원터치 파티 구인 (LFG)
│   │       ├── voice_master.py # 임시 음성방 & 리모컨
│   │       └── moderation.py   # 비밀 신고 티켓 & 경고 시스템
│   ├── config.py             # 게임 목록 및 환경 설정
│   ├── database.py           # aiosqlite 비동기 데이터베이스
│   ├── requirements.txt      # 파이썬 의존성
│   ├── .env.example          # 환경변수 템플릿
│   └── run.py                # FastAPI + 봇 단일 비동기 통합 런처
│
└── frontend/                 # Next.js 웹 대시보드
    ├── src/app/
    │   ├── globals.css       # 게이밍 다크 테마 & 글래스모피즘
    │   ├── layout.tsx        # SEO 및 메타데이터
    │   └── page.tsx          # 5개 탭 종합 관리 관제 대시보드
    └── package.json
```

## 🚀 빠른 시작 가이드

### 1. 백엔드 및 봇 실행 (Python)

```bash
# 1) backend/.env 파일 생성 및 디스코드 봇 토큰 입력
copy backend\.env.example backend\.env
# backend/.env 열어서 DISCORD_TOKEN 입력

# 2) 실행 (가상환경 사용)
.\.venv\Scripts\python backend\run.py
```
> 토큰을 아직 넣지 않았더라도 `FastAPI` API 서버(`http://127.0.0.1:8000`)는 바로 가동되어 웹 대시보드를 바로 둘러보실 수 있습니다.

### 2. 웹 대시보드 실행 (Next.js)

```bash
cd frontend
npm run dev
```
브라우저에서 `http://localhost:3000` 접속!

봇을 새 서버에 초대한 후, 관리자 권한으로 아래 슬래시 명령어를 원하는 채널에서 실행하세요:

| 명령어 | 추천 채널 | 설명 |
| :--- | :--- | :--- |
| `/setup_onboarding` | `#인증-규칙` | 🔞 성인 인증 버튼 및 게임 역할 선택 드롭다운 패널 설치 |
| `/setup_party_hub` | `#파티-구인` | 원터치 파티 모집 생성 버튼 패널 설치 |
| `/setup_voice_master` | (아무 채널) | `🔊 음성 채널` 카테고리와 `➕ 방 만들기` 채널 자동 생성 |
| `/setup_ticket_hub` | `#신고-문의` | 1:1 관리자 비밀 상담 및 신고 티켓 창구 설치 |
